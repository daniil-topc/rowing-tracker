# Трекер тренировок по гребле — Telegram Mini App

Личный трекер для гребцов: отмечаешь, была ли тренировка (на воде или в зале), а для воды — отрезки, километры и время.

## Возможности
- Отметка дня: Да / Нет + Вода / Зал
- Тренировка на воде: отрезки (повторы × метры), общий километраж, время и средний темп на 500 м
- Сезон определяется по последней тренировке (если отметок нет — по месяцу)
- Календарь с цветами: вода, зал, пропуск; можно отметить прошедший день
- Статистика за неделю / месяц / год и километры на воде по месяцам
- Серия тренировок подряд и лучшая серия

## Стек
HTML, CSS, JavaScript (ES-модули), Telegram Mini Apps API. Без фреймворков и без сервера.

## Как хранятся данные
- В Telegram — `Telegram.WebApp.CloudStorage`: у каждого пользователя своё хранилище, синхронизируется между устройствами.
- В обычном браузере — `localStorage` (для разработки).
- Один ключ на месяц: `"2026-10"` → `{ "14": { t: "w", s: 3520, g: [["Разминка", 1, 3000]] } }`.

## Структура
```
index.html        — разметка и контейнеры экранов
css/style.css     — стили (тёмная тема, цвета в :root)
js/app.js         — состояние, отрисовка экранов, обработчики
js/storage.js     — CloudStorage / localStorage
js/stats.js       — серии, посещаемость, километры, сезон
js/dates.js       — даты и форматирование
```

## Запуск локально
```
python -m http.server 5500
```
Открыть http://localhost:5500

## Подключение к боту
1. Выложить папку на GitHub Pages (нужен HTTPS).
2. В @BotFather: `/newbot` — создать бота.
3. В @BotFather: настройки бота → Mini App / Menu Button → указать ссылку на GitHub Pages.
